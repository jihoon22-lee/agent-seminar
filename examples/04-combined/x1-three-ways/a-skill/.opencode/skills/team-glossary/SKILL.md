# 팀 용어 사전 조회

팀 용어의 뜻은 추측하지 말고 반드시 사전에서 찾는다. 팀마다 값(목표 수치, 절차)이 달라서 일반 지식과 다를 수 있다.

## 절차

1. 사용자가 물은 용어를 하나 정한다. (여러 개면 하나씩)
2. 프로젝트 루트에서 아래 명령을 실행한다. `python` 명령이 없는 Linux 에서는 `python3` 를 쓴다.

   ```
   python .opencode/skills/team-glossary/scripts/lookup.py "<용어>"
   ```

3. 출력된 문장을 근거로 한두 문장으로 답한다. 사전에 없다고 나오면 등록된 용어 목록을 보여 주고, 뜻을 지어내지 않는다.
