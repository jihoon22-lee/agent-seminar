# 버전 관리 규칙

- 버전은 **경로 접두사**로 표시한다: `/v1/orders`. 헤더나 쿼리 파라미터로 버전을 고르지 않는다.
- 하위 호환이 되는 변경(필드 추가, 새 엔드포인트, 새 선택 파라미터)은 같은 버전에서 배포한다.
- 호환이 깨지는 변경(필드 삭제·이름 변경, 타입 변경, 필수 파라미터 추가, 정렬 순서 변경)은 새 메이저 버전(`/v2`)으로만 낸다.
- 폐기 예정 버전의 모든 응답에는 `Deprecation: true`와 `Sunset: <종료일 HTTP-date>` 헤더를 붙인다.
- 폐기 공지부터 종료까지 최소 **180일**을 둔다. 한 번에 유지하는 메이저 버전은 최대 두 개다.
