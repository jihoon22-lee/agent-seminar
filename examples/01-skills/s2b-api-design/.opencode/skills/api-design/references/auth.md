# 인증·권한 규칙

- 모든 요청은 `Authorization: Bearer <access_token>` 헤더로 인증한다. 토큰을 쿼리 문자열에 넣지 않는다.
- 액세스 토큰 수명은 **15분**, 갱신은 `POST /v1/auth/refresh`로 한다.
- 권한은 `리소스:동작` 형태의 스코프로 표현한다: `orders:read`, `orders:write`. 엔드포인트마다 필요한 스코프를 설계 결과에 명시한다.
- 인증 정보가 없거나 만료되면 `401`, 인증은 됐지만 스코프가 부족하면 `403`이다.
- 남의 리소스를 조회할 때는 존재 여부를 숨기기 위해 `403`이 아니라 `404`를 돌려준다.
- 결제·주문 생성 같은 `POST`는 `Idempotency-Key` 헤더를 받아 같은 키의 재시도를 한 번만 처리한다.
