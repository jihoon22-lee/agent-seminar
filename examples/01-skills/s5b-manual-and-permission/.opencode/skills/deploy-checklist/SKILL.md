# 배포 체크리스트 (DEPLOY-CHECKLIST-V3)

사용자가 알려 준 서비스·버전(인자)에 맞춰 아래 순서대로 점검 결과를 정리해 주세요.
인자가 없으면 먼저 어떤 서비스를 어떤 버전으로 배포하는지 물어보세요.

1. 메인 브랜치 CI가 초록인지 확인한다.
2. 데이터베이스 마이그레이션이 있으면 롤백 스크립트까지 준비돼 있는지 확인한다.
3. 롤백 담당자 한 명을 지정한다.
4. 기능 플래그로 끌 수 있는 변경인지 확인한다.
5. 배포 공지 문구를 채널에 올릴 초안으로 작성한다.

마지막에 "확인 필요" 항목만 따로 모아 한 줄씩 보여 주세요. 이 스킬은 직접 배포를 실행하지 않습니다.
