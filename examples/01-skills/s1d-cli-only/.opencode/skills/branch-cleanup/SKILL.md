# 병합된 브랜치 정리

이 스킬은 스크립트 없이 `git` 명령만 쓴다. 아래 명령은 한 줄에 하나씩, 그대로 실행한다.
명령을 `&&`, `|`, `;`, `$(...)`, `xargs` 로 이어 붙이지 않는다. (Windows PowerShell 5.1 과 bash 에서 똑같이 동작시키려는 규칙이다.)

## 규칙

1. 삭제 후보는 `git branch --merged main` 이 보여 주는 브랜치뿐이다. 목록에 없는 브랜치는 지우지 않는다.
2. `main` 과 지금 체크아웃한 브랜치는 절대 지우지 않는다. 목록에서 `*` 로 시작하는 줄이 지금 브랜치다. `+` 로 시작하는 줄은 다른 작업 폴더에서 쓰는 브랜치이니 지우지 않는다.
3. 삭제는 소문자 d 옵션이 붙은 `git branch -d` 로만 한다. 강제 삭제 옵션(d 의 대문자)은 쓰지 않는다. `git branch -d` 가 "not fully merged" 로 거절하면 강제로 지우지 말고 "보존"으로 보고한다.
4. 원격 브랜치(`git push --delete`, `git remote prune` 등)는 건드리지 않는다.
5. `main` 브랜치가 없으면(기본 브랜치 이름이 다르면) 아무것도 지우지 말고 사용자에게 알리고 멈춘다.

## 순서

1. 지금 브랜치를 확인한다.

```
git branch --show-current
```

2. 병합된 브랜치 목록을 본다.

```
git branch --merged main
```

3. 병합되지 않은 브랜치 목록을 본다. 이것들은 전부 보존이다.

```
git branch --no-merged main
```

4. 2번 목록에서 `main`, `*` 줄, `+` 줄을 뺀 나머지를 **하나씩** 지운다. 브랜치마다 한 번씩 이 명령을 실행한다. `<이름>` 은 목록에 나온 이름 그대로 쓴다.

```
git branch -d <이름>
```

5. 결과를 확인한다.

```
git branch
```

## 보고 형식

표 하나로 보고한다. 열은 `브랜치 | 처리 | 이유` 이다.

| 처리 | 이유 예시 |
| --- | --- |
| 삭제 | main 에 병합됨 |
| 보존 | 기본 브랜치 / 지금 체크아웃한 브랜치 / 다른 작업 폴더에서 사용 중 / main 에 병합되지 않음 / `-d` 가 거절함 |

표 아래에 실행한 `git` 명령을 한 줄씩 나열한다. 실행하지 않은 것은 쓰지 않는다.
