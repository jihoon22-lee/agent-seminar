# 사용자용 한국어 릴리스 노트 문체

릴리스 노트의 독자는 이 제품을 쓰는 사람이다. 커밋 로그를 번역하는 것이 아니라 "내게 뭐가 달라졌나"를 쓴다.

## 규칙

- 한 항목은 한 문장. `~합니다` 대신 명사형 또는 `~했습니다` 중 하나로 통일한다.
- 내부 용어·함수명·파일명·커밋 해시는 쓰지 않는다. (해시는 개발자용 부록에만)
- scope 는 괄호 안 영어 대신 자연스러운 이름으로 풀어 쓴다. `cart` → 장바구니, `auth` → 로그인, `api` → API, `db` → 데이터베이스.
- 사용자가 영향을 받는 동작 변화를 앞에 쓴다. 예: "쿠폰 코드를 입력해 할인받을 수 있습니다."
- 원인보다 결과를 쓴다. 예: "세션이 만료돼도 로그아웃되지 않고 자동으로 갱신됩니다."

## 분류 매핑

| 영문 섹션 | 한국어 제목 |
|---|---|
| Breaking changes | 호환성이 깨지는 변경 (먼저, 대응 방법 포함) |
| Features | 새로운 기능 |
| Bug fixes | 버그 수정 |
| Performance | 성능 개선 |
| Refactoring / Tests / Build / CI / Style / Chores | 내부 개선 (한 줄로 묶거나 생략) |
| Documentation | 문서 |
| Other | 분류되지 않은 변경 — 내용을 보고 위 제목 중 하나로 옮기거나, 알 수 없으면 "기타"에 둔다 |
