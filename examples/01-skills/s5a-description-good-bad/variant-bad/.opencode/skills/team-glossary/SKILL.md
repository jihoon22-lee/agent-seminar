# 팀 용어 사전 (TEAM-GLOSSARY-BODY)

이 팀에서만 쓰는 용어입니다. 질문에 답할 때는 아래 정의를 그대로 따르세요.

- 블루문: 분기 마지막 주 금요일에 하는 코드 동결. 이날 이후엔 핫픽스 외에는 머지하지 않는다.
- 팔콘: 결제 배치 서비스(payment-batch)의 내부 코드네임.
- RFC-lite: 한 쪽 이하로 쓰고 리뷰어 2명 승인으로 끝내는 가벼운 설계 제안서.
- 그린데이: 배포 파이프라인이 24시간 내내 초록색이었던 날. 다음 날 아침 회의에서 한 줄 자랑을 한다.
- 핫포테이토: 새벽 알림을 넘겨받을 사람을 정하는 온콜 인수인계 의식. 인수 메시지는 슬랙 #oncall 에 남긴다.
