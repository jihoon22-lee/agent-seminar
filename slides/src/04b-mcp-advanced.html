M7도구 말고도: resources와 prompts

prompts → / 명령이 된다

  • 서버가 준 프롬프트가 /runbooks:incident-report 같은 명령으로 TUI 자동 완성에 뜬다
  • 인자는 opencode가 직접 끼워 넣는다. 서버는 "$1" 같은 자리표시만 받는다
  • CLI에서는 opencode run --command runbooks:incident-report INC-1

resources → @로 첨부한다

  • TUI에서 @를 치면 runbook://payment/restart 같은 문서가 목록에 뜬다
  • 서버에 resources가 있으면 모델에게 list_mcp_resources, read_mcp_resource 도구가 생긴다

언제 쓰나: 팀 런북, 장애 대응 문서처럼 "사람이 골라서 첨부할 문서"는 resources, 자주 쓰는 질문 틀은 prompts로 내보내면 팀 전체가 같은 형식을 씁니다.

capabilities에 prompts, resources를 선언하지 않은 서버에는 opencode가 묻지 않습니다.

examples/02-mcp/m7-resources-prompts

대부분의 MCP 서버는 tools만 씁니다. resources, prompts는 TUI에서 사람이 고를 때 빛납니다. opencode run에서는 --command만 됩니다.

인자 치환을 opencode가 한다는 점은 의외였습니다. 서버의 prompts/get에는 "$1"이 그대로 옵니다.

M8도구가 많아지면: 끄고, 숨기고, 재 보기

  • "enabled": false: 서버 자체를 띄우지 않는다. mcp list에 ○ disabled
  • permission에서 deny한 도구는 모델에게 아예 전달되지 않는다. ask는 목록에는 남는다
  • agent.<이름>.tools로 에이전트마다 다르게 줄 수 있다. --agent reviewer는 운영 도구와 파일 수정 없이 동작한다
  • 나중에 쓴 규칙이 이긴다. 예전 형식 "tools": {"x_*": false}도 같은 deny 규칙으로 바뀐다

측정해 보니: 도구 12개짜리 서버 하나를 켜면 매 요청마다 약 1,600 토큰이 늘었습니다. 안 쓰는 서버는 끄고, 안 쓰는 도구는 deny로 숨기세요.

examples/02-mcp/m8-enable-disable-deny

토큰 수는 count_tool_tokens.py로 도구 설명 크기를 재고, 가짜 모델 서버로 opencode가 실제로 보낸 요청을 기록해서 확인했습니다.

예전 형식의 "tools": {"x_*": false}도 같은 deny 규칙으로 바뀝니다.
