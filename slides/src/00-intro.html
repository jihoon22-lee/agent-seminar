필요한 것

  • opencode 1.19.5 이 버전으로 모든 예제를 검증
  • Python 3.10 이상 예제 스크립트와 MCP 서버는 표준 라이브러리만 사용
  • git
  • 모델: 평소 쓰는 모델 그대로. 설정된 모델이 없으면 무료 모델 opencode/big-pickle

인터넷 없이 돌아가도록 만들었습니다. 다만 .opencode/ 폴더가 있는 예제는 처음 실행할 때 opencode가 npm 패키지 하나(@opencode-ai/plugin)를 설치하려 합니다. 레지스트리나 미러가 없으면 첫 시작이 1분쯤 멈췄다가 그대로 진행됩니다. 플러그인 단위 테스트에는 Node가 있으면 좋습니다.

README.md

예제 폴더 하나하나가 그 자체로 opencode 프로젝트입니다. 해당 폴더로 들어가서 opencode를 실행하면 그 예제의 설정만 적용됩니다.

Linux에서 python 명령이 없으면 예제 설정의 python을 python3로 바꾸면 됩니다. README마다 적어 두었습니다.

에이전트는 코드를 잘 짭니다.
그런데 우리 팀은 모릅니다.

커밋 규칙, 리뷰 기준, 장애 티켓이 쌓인 시스템, 절대 하면 안 되는 명령.

모델은 인터넷 전체로 학습했지만, 우리 팀이 어제 정한 규칙이나 팀 안에만 있는 시스템은 알 수 없습니다.

매번 프롬프트로 설명하면

이런 일이 반복됩니다

  • "커밋 메시지는 type(scope): 요약 형식이고…"를 매번 붙여 넣는다
  • 사람마다 설명이 달라서 결과가 들쭉날쭉하다
  • 티켓 시스템 내용은 복사해서 붙여 넣어야 한다
  • ".env는 읽지 마"는 부탁일 뿐, 지켜진다는 보장이 없다

핵심 메시지: 반복되는 설명을 "확장"으로 바꾸면 매번 쓰는 비용이 사라지고, 팀원 모두가 같은 결과를 얻습니다.

특히 마지막 줄. 프롬프트로 하는 금지는 부탁입니다. 플러그인이나 권한 설정은 강제입니다. 이 차이를 오늘 여러 번 봅니다.

opencode를 처음 보는 분을 위해

  • 터미널에서 쓰는 오픈소스 코딩 에이전트
  • 모델을 고를 수 있다 유료 API, 직접 띄운 모델, 무료 모델
  • 파일 읽기, 수정, 명령 실행 같은 기본 도구를 갖고 있다
  • 설정은 opencode.json 하나로 한다

오늘 데모는 대부분 opencode run으로 보여 드립니다. 결과가 바로 터미널에 찍혀서 보기 편하기 때문입니다. 실제로 쓸 때는 TUI가 편합니다.
