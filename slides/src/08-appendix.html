문서를 볼 때: 버전을 먼저 확인하세요

opencode는 빠르게 바뀝니다. 공식 문서 사이트에는 다음 버전의 설정 형식이 먼저 올라와 있습니다.

1.19.5 (이 자료)문서의 새 형식
"mcp": { "이름": {…} }"mcp": { "servers": {…} }
"plugin": [ … ]"plugins": [ … ]
"enabled": false"disabled": true

1.19.5에 새 형식을 쓰면 plugins 같은 최상위 키는 오류 없이 무시되고, mcp 안의 형식 차이는 시작 오류가 납니다.

버전을 올리면 opencode debug config와 python tools/run_checks.py examples로 다시 확인하세요. 동작이 달라지면 해당 예제의 check.py가 실패해서 알려 줍니다.

자동 업데이트가 켜져 있으면 어느 날 갑자기 형식이 바뀝니다. 팀에서 쓸 때는 버전을 맞춰 두는 것을 권합니다.
